# Artist Portfolio

A polished Next.js portfolio for showcasing an artist's work — hero, featured pieces, full gallery, about, and contact — with dark/light themes and smooth motion.

Built for **Israa Farahat**'s collection, and easy to adapt for any visual creator who wants a clean public site.

## Who it's for

- Artists and creatives who need a modern portfolio online
- Studios or agencies spinning up a client showcase quickly
- Anyone who wants gallery + about + contact without a heavy CMS

## What you get

- Hero + featured works on the home page
- Full gallery with artwork modal detail
- About and contact pages
- Theme toggle (light / dark / system)
- Docker + nginx ready for self-hosting
- Live demo: [artist-portfolio-jade-zeta.vercel.app](https://artist-portfolio-jade-zeta.vercel.app)

## Try it

**Live:** [Open the site](https://artist-portfolio-jade-zeta.vercel.app)

**Local:** install dependencies with your Node package manager, then run the `dev` script from `package.json` (Next.js defaults to http://localhost:3000).

**Docker:** from the repo root, build and start with Compose using the included `Dockerfile` / `docker-compose.yml` (nginx front).

## Stack

Next.js · React · TypeScript · Tailwind · Framer Motion · shadcn/ui

## More

Ops notes live in `Dockerfile`, `nginx.conf`, and `docker-compose.yml`.
